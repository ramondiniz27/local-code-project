📌 Instruções de Primeira Instalação

🍏 Como abrir no macOS (Aviso de Desenvolvedor Não Verificado) +
Como este é um projeto open-source sem certificação paga da Apple ($99/ano), o macOS Gatekeeper pode alertar na primeira inicialização. Para autorizar com segurança:
  1. Abra o arquivo .dmg e arraste o local-code para a pasta Aplicativos.
  2. Clique com o botão direito (Control + Clique) sobre o ícone do local-code em Aplicativos e selecione Abrir.
  3. Na janela de confirmação, clique em Abrir.
  4. Ou execute no Terminal: xattr -cr /Applications/local-code.app
🐧 Como executar o AppImage no Linux +
Após baixar o arquivo .AppImage:
  1. Abra o terminal na pasta de Downloads e dê permissão de execução:
    chmod +x local-code_*.AppImage ./local-code_*.AppImage
  2. Em distribuições recentes (Ubuntu 22.04+), certifique-se de que o FUSE esteja instalado: sudo apt install libfuse2
🪟 Aviso do Windows Defender SmartScreen +
No primeiro lançamento no Windows Defender SmartScreen:
  1. Clique em Mais informações na tela azul do SmartScreen.
  2. Clique no botão Executar assim mesmo.

Compilar a Partir do Código Fonte

Execute no modo de desenvolvimento ou gere seus próprios binários localmente

bash — setup e desenvolvimento local pnpm tauri dev
# 1. Clone o repositório oficial
git clone https://github.com/ramondiniz27/local-code-project.git
cd local-code-project
# 2. Instale as dependências do projeto
pnpm install
# 3. Inicie o aplicativo em modo de desenvolvimento
pnpm tauri dev
# 4. Ou compile os instaladores nativos de produção
pnpm tauri build
